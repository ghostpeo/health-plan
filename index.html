Week 1 — 3 Sets × 5 Reps

Foundation week. Focus on movement quality above all. Sets at 65% / 75% / 85% of working max. Leave at least one rep in the tank — especially Tuesday before Wednesday tennis.

5/3/1 Intensity Guide — Week 1

SetIntensityRepsFeel
Set 165%5Easy warm-up pace
Set 275%5Moderate — controlled
Set 385%5Challenging — stop before failure
Starting weight rule: Start embarrassingly light. If you think your squat working max is 60kg, use 40kg as your 100% for the first cycle. You can always add weight — you can't un-injure a tendon.

Week 2 — 3 Sets × 3 Reps

Intensity increases, volume drops. Sets at 70% / 80% / 90%. Same exercises — only the main lift percentages change.

5/3/1 Intensity Guide — Week 2

SetIntensityRepsFeel
Set 170%3Solid warm-up

Refer to Week 1 for the full exercise list and videos. Only the main lift intensity changes this week.

Week 3 — 5 / 3 / 1 Singles

Peak week. Sets at 75% / 85% / 95%. The last set is max effort — push it, keep form intact.

5/3/1 Intensity Guide — Week 3

SetIntensityRepsFeel
Set 175%5Controlled opener
Set 285%3Serious working set
Set 395%1+Max effort — as many as possible with good form
The + means AMRAP on the last set. More than 5 reps at 95% means your working max was set too low — adjust upward next cycle.

Week 4 — Deload

Not optional. Connective tissue adapts slower than muscle — it needs this week. Drop to 40–60%. Move well, recover fully. You will feel stronger in Week 1 of the next cycle.
