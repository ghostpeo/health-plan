Week 1 — 3 Sets × 5 Reps

Foundation week. Focus on movement quality above all. Sets at 65% / 75% / 85% of working max. Leave at least one rep in the tank on every set — especially Tuesday before Wednesday tennis.

5/3/1 Intensity Guide — Week 1

Set 165%5Easy warm-up pace
Set 275%5Moderate — controlled
Set 385%5Challenging — stop before failure
Starting weight rule: Start embarrassingly light. If you think your squat working max is 60kg, use 40kg as your 100% for the first cycle. You can always add weight — you can't un-injure a tendon.

Week 2 — 3 Sets × 3 Reps

Intensity increases, volume drops. Heavier weight, fewer reps. Sets at 70% / 80% / 90%. Everything else stays identical — same exercises, same structure. Focus on bar speed and crisp technique.

5/3/1 Intensity Guide — Week 2

SetIntensityRepsFeel
Set 170%3Solid warm-up
Set 280%3Working hard
Set 390%3Heavy — 1–2 reps left in tank
Week 2 focus: Same sessions as Week 1 — just adjust the main lift percentages. All supplemental, push/pull, and assistance work stays the same sets and reps. The only thing changing is the 3 main lift sets.
Refer to Week 1 sessions for the full exercise list and video links. Only the main lift intensity changes this week.

Week 3 — 5 / 3 / 1 Singles

Peak week. The classic 5/3/1 ladder. One heavy top set. Sets at 75% / 85% / 95%. The last set at 95% is your max effort for the cycle — push it, but keep form intact.

5/3/1 Intensity Guide — Week 3

SetIntensityRepsFeel
Set 175%5Controlled opener
Set 285%3Serious working set
Set 395%1+Max effort — do as many as possible with good form
The + means AMRAP (as many reps as possible) on the last set. If you get more than 5 reps at 95%, your working max was set too low — good news, you adjust upward next cycle. All supplemental and assistance work stays the same as Weeks 1–2.

Week 4 — Deload

This is not optional. Your connective tissue adapts slower than your muscles — it needs this week. Drop intensity to 40–60%. Move well, stay active, recover fully. You will feel stronger in Week 1 of the next cycle.

Deload Parameters

Sets3–42–3
Reps3–85

Deload week strategy: Same exercises, same structure. Just drastically lighter. Focus on perfect movement quality. Use this week to also assess any niggles or tightness before the next cycle. After Week 4, add 2.5kg to upper body lifts and 5kg to lower body lifts for the next cycle.
Summer adjustment: When golf season starts, deload week intensity naturally aligns with golf days. Your body gets systemic recovery even while staying active.
